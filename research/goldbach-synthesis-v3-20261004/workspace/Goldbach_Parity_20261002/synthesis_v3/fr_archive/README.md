request for an English PDF on 4 October 2026. They are historical snapshots;
their original contents and SHA-256 hashes have not been rewritten.

The French `evidence_v3.json` and `DELIVERY_V3.json` retain the paths used at that
time. In particular, the historic manuscript binding
`synthesis_v3/goldbach_synthesis_v3.tex` refers to the French file now retained
here, with SHA-256
`222f187546550d9f03589e219e008d11e07e6c0e1a85f39834c3e1e8319c02f1`.
Resolve the historic French manuscript and PDF against this directory when
checking those old document bindings. The research files and scientific
receipts remain at their original relative locations in the complete snapshot.

`output_pdf/` retains the French build outputs and logs; `tmp_pdf_qa/` retains
the French rendered pages and layout checks. The current manuscript, PDF,
evidence registry and delivery outside this directory describe the English
edition. This translation introduces no new scientific execution or result.
