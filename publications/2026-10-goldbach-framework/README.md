## Reproduction

Unzip into a new directory and read README.txt. Inspect the portable Lean replay driver and the exact dependency pins before running. Do not treat an old compiled artifact as a new source replay. The analytic checkers verify arithmetic guards, not zero-free regions or asymptotic theorems.
