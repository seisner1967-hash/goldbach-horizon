# TS118 Audit - Selberg LCM Absorption Bridge

## Status

`repo_committed`

TS117 proves that the current gcd-only coefficient compatibility cannot match
the canonical dense `gcd/lcm` kernel. TS118 records and proves the local
correction: absorb the `1/m` and `1/n` factors into the weights, then replace
the pair-sensitive `gcd/lcm` kernel by a gcd-square kernel.

The core termwise identity is:

```text
w(m) * w(n) * gcd(m,n)/lcm(m,n)
=
(w(m)/m) * (w(n)/n) * gcd(m,n)^2
```

It is proved over `Rat`, including the zero-index cases generated by
`Finset.range (level + 1)` under Lean's totalized division.

This sprint does not prove the corrected diagonalization, the square-sum
majorant, Selberg's sieve, Brun-Titchmarsh, interval majorant, budget
comparison, or any prime-count estimate. It gives the equality bridge needed
before a corrected diagonalization can be introduced.

## Proof summary

The theorem

```lean
TS118.Goldbach.canonicalSelbergQuadraticKernel_eq_gcdSquare_div_mul
```

proves the arithmetic kernel rewrite:

```text
gcd(m,n)/lcm(m,n) = gcd(m,n)^2/(m*n)
```

over `Rat`. The proof handles `m = 0` and `n = 0` separately, then uses
`Nat.gcd_mul_lcm`, `field_simp`, and `ring` in the nonzero case.

The theorem

```lean
TS118.Goldbach.selbergQuadraticFormTerm_eq_gcdSquareAbsorbedTerm
```

absorbs the denominator into the two weights:

```text
w(m) * w(n) * gcd/lcm
=
(w(m)/m) * (w(n)/n) * gcd^2
```

The theorem

```lean
TS118.Goldbach.selbergDenseSide_eq_gcdSquareDenseSide_absorbed
```

lifts the termwise equality through the TS108 finite double sum with
`Finset.sum_congr`.
